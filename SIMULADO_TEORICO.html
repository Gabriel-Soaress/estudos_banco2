QUESTÃO 7 • CAÇA AOS ERROS: PROCEDURE E SELECT ... INTO Não respondida

Analise a procedure abaixo. Ela compila sem erros, mas possui 1 bug lógico (o nome do usuário sai em branco no terminal) e 1 bomba-relógio que faz a procedure quebrar com ORA-01422 se o usuário tiver dois treinos empatados com a maior duração. Aponte onde estão esses dois problemas e como corrigi-los:

CREATE OR REPLACE PROCEDURE PRC_RESUMO_TREINO (p_cod_usr IN VARCHAR2) IS
    v_id_usr   TRE_USUARIO.ID_USUARIO%TYPE;
    v_nome_usr TRE_USUARIO.NOME%TYPE;
    v_maior_t  NUMBER;
    v_cod_tr   TRE_TREINO.COD_TREINO%TYPE;
BEGIN
    SELECT ID_USUARIO INTO v_id_usr
    FROM TRE_USUARIO WHERE COD_USUARIO = p_cod_usr;

    SELECT MAX(DURACAO_MINUTO) INTO v_maior_t
    FROM TRE_TREINO WHERE ID_USUARIO = v_id_usr;

    SELECT COD_TREINO INTO v_cod_tr
    FROM TRE_TREINO
    WHERE ID_USUARIO = v_id_usr AND DURACAO_MINUTO = v_maior_t;

    DBMS_OUTPUT.PUT_LINE('Nome: ' || v_nome_usr || ' | Treino: ' || v_cod_tr);
END;
QUESTÃO 8 • CAÇA AOS ERROS: FUNCTION, %ROWTYPE E CASE Não respondida

A Function abaixo tem 3 erros clássicos de PL/SQL (um no cabeçalho, um no uso do %ROWTYPE e um no CASE). Identifique os 3 erros:

CREATE OR REPLACE FUNCTION FNC_AVALIAR_META (p_id_meta IN NUMBER)
RETURN VARCHAR2(50) IS
    v_meta TRE_META%ROWTYPE;
    v_msg  VARCHAR2(50);
BEGIN
    SELECT CARGA_ALVO, STATUS
    INTO v_meta
    FROM TRE_META
    WHERE ID_META = p_id_meta;

    CASE
        WHEN v_meta.CARGA_ALVO >= 100 THEN v_msg := 'META PESADA';
        WHEN v_meta.CARGA_ALVO >= 50  THEN v_msg := 'META MEDIA';
    END CASE;

    RETURN v_msg;
END;
